## Overview

GopherFeed is a Go service that aggregates RSS and Atom feeds into a shared
PostgreSQL database. Users register, add feeds, and follow feeds created by
other users. A background scraper continuously fetches and parses feed documents
without blocking the HTTP API.

## Concurrency model

- Bounded worker pool for feed fetching and XML parsing
- Channel-based handoff between the scheduler and parse workers
- Fixed concurrency ceiling to control connection and memory pressure
- Per-feed fetch intervals persisted in PostgreSQL
- Graceful shutdown of in-flight workers

## Data layer

- PostgreSQL with `sqlc` for type-safe query generation
- `goose` migrations for schema versioning
- `chi` router and API-key authentication
- Separate read and write paths for feed metadata and posts

## Stack

Go, PostgreSQL, `sqlc`, `goose`, `chi`, `lib/pq`.
