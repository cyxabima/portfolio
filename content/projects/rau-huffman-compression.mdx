## Overview

RAU is a lossless text-file compressor built around a from-scratch Huffman
coding pipeline. The project implements frequency analysis, tree construction,
code assignment, and binary serialization without relying on a compression
library.

## Implementation

- Byte-frequency analysis over the input stream
- Min-heap priority queue for Huffman tree construction
- Variable-length code assignment from tree traversal
- Custom bit-level writer and reader for packed code streams
- Serialized tree header for deterministic decompression
- Electron desktop shell for filesystem access

## Stack

Python for the compression core, Electron and Node.js for the desktop
application, with HTML/CSS/JavaScript for the interface.
