## Overview

ProLog replaces the physical archive of Final Year Design Projects (FYDPs) at NED University's Textile Engineering Department with a searchable, role-scoped web application. The backend is an Express/TypeScript service that talks directly to PostgreSQL without an ORM.

## Backend architecture

- Express and TypeScript with a stateless JWT session model
- Raw SQL data-access layer for explicit query control
- PostgreSQL schema with JSONB audit logs and disjoint constraints
- Paginated catalogue search using indexed `ILIKE` and complex joins
- Aggregation queries for department, domain, and archive metrics
- bcrypt password hashing and four-tier role-based access control

## Scope

- Guest, faculty, staff, and admin roles
- Project catalogue with domain and department filters
- PDF report, source archive, and grant linkage
- User, department, and industry-partner administration
- Audit logging for state changes
